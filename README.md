# 🌐 SosaSpeaks (sosaspeaks.org)

> "How it is we have so much information, but know so little?"

Welcome to the repository for **SosaSpeaks**, an independent web-zine and archive dedicated to long-form commentary across ethics, media, politics, and history. Built independently with pure vanilla HTML, CSS, and JavaScript.

---
## Stack & Deployment
* **Frontend:** Vanilla HTML5, Modern CSS3 (Flexbox/Grid), Native JavaScript
* **DNS & Performance Engine:** Cloudflare Domains
* **Hosting Environment:** GitHub Pages

## Navigation & Special Pages
* `/index.html` — The main publication portal.
* `/about.html` — About the authors/contributors.
* `[Upcoming]` Merch Gallery — A custom catalog archiving limited-edition physical drops.
* `[Upcoming]` Art Gallery — A digital gallery displaying the works of associates.
